## Description
Field teams reset their survey tablets between rounds. The server says everything was received, but a record can arrive without its photo, and the only copy disappears with the reset.

LastCopy gives one answer per tablet before the wipe: safe to wipe, recover first, or hold. Agents investigate: Zetaris joins the tablet exports, server, spreadsheet and file objects in place, NVIDIA Nemotron (via Meterless Nightshift) forms and critiques hypotheses, and a Meterless World Model plans every step. Then code compares the original bytes. Models never decide. An Adversary attacks every clearance, and each decision ships with a certificate anyone can re-check.

Live run (27 Oct 2026): 7 Zetaris queries, 7 Nemotron calls, 0 fallbacks.
Blind tests: 500 random fleets, 1,980 of 1,980 tablets correct, 0 wrongly cleared.

This is a recording plan, not a claim that a video has been recorded. Use only
synthetic test data. Prepare the services and an incomplete synthetic record
before recording. Keep credentials and native provider Setup screens out of view.
If services fail, show the failure or use an explicitly labelled saved capture;
never call it live. Keep Sample, Replay and Connected labels visible.

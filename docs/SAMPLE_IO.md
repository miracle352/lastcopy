# Bundled sample input/output pairs

Each directory contains `run-manifest.json`, `device.zip`,
`server-snapshot.json`, `server-payload.zip` and independently authored
`expected.json`. Seeded builders are in `scripts/build_stage2_fixtures.py` and
`build_stage3_fixtures.py`. Expected outcomes are not generated by the comparator.

| Input directory | Expected result / useful action |
| --- | --- |
| `fixtures/stage2/media` | MISSING_ATTACHMENT; shared filename twice remains one slot, equal bytes in two different filenames still require both slots |
| `fixtures/stage2/stranded` | One PRESERVED and two MISSING_SUBMISSION; totals do not identify the missing records |
| `fixtures/stage2/export` | EXPORT_VIEW_ONLY, positively preserved; use an export including repeats, no data upload |
| `fixtures/stage2/history` | PRESERVED matching original history; retain newer intentional edit, no overwrite |
| `fixtures/stage3/export-review` | EXPORT_VIEW_ONLY; connected reviewer requests raw XML and hypothesis is rejected |
| `fixtures/stage3/unresolved-conflict` | CONTENT_CONFLICT; manual review, no automatic recovery |
| `fixtures/stage3/held-out` | Changed IDs/paths and five repeat occurrences; EXPORT_VIEW_ONLY, no upload |

Run any directory using the README CLI command with its four input paths.
The UI sample catalog exposes media, stranded, export, history and conflict
without JSON editing. Actual CLI results/hashes for all seven packs are retained
in `verification/stage7/cli.json`; actual UI reports/download hashes are in
`verification/stage7/offline-browser.json`.
Three actual CLI report outputs are also retained in
`verification/stage7/sample-outputs/{media,export,history}.json`. These are
observed comparator outputs; the independent expected outcomes remain in each
fixture's `expected.json`.

Sample IO is synthetic and scoped. The offline recovery example compares a
separately authored readback pack; it is never described as a real upload. Real
Central recovery receipts are separately labelled Connected. Regression tests
also cover absent devices, unknown completion, absent original forms, mismatched
scope, malformed/hostile ZIP/XML, unavailable history/attachments and permission
failure; these do not silently become recovery or full assurance.

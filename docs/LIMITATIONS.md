# Limits of the checked copy

The later [hosted pilot](CLOUD_PILOT.md) adds single-owner HTTPS access, persistent
AWS services and a bounded paired-emulator relay. Daily encrypted off-host
backups are now active; isolated S3 restoration of SQLite, Central and Enketo
components passed. See [BACKUP_ACTIVATION.md](BACKUP_ACTIVATION.md). This does not
establish a full host rebuild, high availability, physical-phone acceptance or
an always-on combined sponsor runtime. Vercel serves the introduction; full-size
private files use AWS.

LastCopy assesses supplied snapshots, an explicit roster and the checked
project/form/version scope. A completed investigation is not complete source
coverage or a successful recovery. There is no authorization to erase a device.

- First-release platform: tested ODK Central v2026.3.1 and Collect v2026.3.5
  emulator export, plus authored synthetic controls. See `COMPATIBILITY.md`.
  No universal historic Collect or Kobo compatibility claim.
- Device ZIPs require original XForms, instance paths, file references and
  explicit completion metadata. Drafts/unknowns are inventoried; they cannot
  silently become automatic submission candidates. Encrypted exports are
  unsupported. Missing source bytes cannot be reconstructed.
- An absent expected device, incomplete source/history, ambiguous mapping,
  failed authenticated request or unreadable required attachment prevents
  complete coverage. HTTP failure is not evidence of record absence.
- Identity includes submission/version and filename slot. Shared references
  may use one slot; differently named equal-byte files still need both slots.
  History is compared separately from intentional current edits.
- A SHA-256 receipt proves checked-byte integrity, not server authentication,
  respondent truth or ownership. Connected provenance records the actual
  configured service and query/readback, with credentials omitted.
- Recovery is restricted to the reviewed dedicated synthetic Central project,
  missing submissions and supported current-version missing media. Conflicting
  answers, unknown mappings and unsupported historical writes remain manual.
  Upload acknowledgement alone is not preservation; fresh readback is required.
- The live Zetaris implementation normalizes bounded synthetic evidence to
  small CSVs in the existing local NDP store. SQL scopes select source objects
  and observations; the comparator then checks retrieved original bytes. It is
  not general in-place federation or a benchmark of warehouse scalability.
- World Model persistence is the tested append-only journal/rebuild through
  the pinned reference. No unimplemented hosted persistence API is claimed.
  Nightshift/cloud availability is external. Outage remains failed/partial;
  there is no silent sample fallback or guaranteed NVIDIA award eligibility.
- Single-user local persistence and loopback browser/API boundaries are
  implemented. This is not an authenticated multi-user hosted service. The
  Vercel preview cannot access private evidence. Do not publish this API or
  expose a tunnel; review authentication, durable storage, encryption, retention
  and operational controls before any future hosted product.
- Audits use Chromium on Windows, lab mobile simulation and CSS 200% zoom.
  They do not establish field INP/Core Web Vitals, cross-browser compatibility
  or screen-reader certification. Actual performance results and unmet goals
  belong in `STAGE7.md`, not an invented marketing claim.

Use **Sample** for actual offline synthetic comparisons, **Replay** for an
identified supplied capture without live inference, and **Connected** for the
actual configured services. A saved connected receipt is a record of its capture
time, not evidence that a provider is currently healthy.

## Wipe gate and certificates (27 Oct 2026)

- The live connected run used the bundled synthetic five-tablet fixture, not data from a real survey team.
- A certificate proves which bytes were compared under rule `lastcopy-wipe-gate/1`. It does not prove the answers are true and covers only the exports supplied.
- A tablet whose export was not supplied is always HOLD. LastCopy never infers its contents.
- Sample mode replaces the four judgement roles with a written offline policy, and every trace line says so.

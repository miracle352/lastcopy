# Pitch deck outline — Track 02

This is deck content, not a submitted slide file or sponsor endorsement.

1. **Bring every record home.** Field coordinators closing an ODK collection
   campaign need evidence that surviving answers and attachments reached Central.
2. **The gap behind the total.** Counts conceal stranded submissions, omitted
   repeat exports and missing filename slots. Use an actual synthetic result,
   labelled Sample. No invented affected-user statistics.
3. **A checked copy, with a trail.** Add exports/roster → compare original
   versions and media → inspect scoped findings → review a permitted plan →
   fetch fresh readback. Use actual product screenshots.
4. **An agent that changes its mind.** Show the retained export-review trace:
   initial missing-data hypothesis, reviewer request for raw XML, ordered repeat
   evidence, rejected hypothesis and export guidance. Include actual capture ID.
5. **Architecture and sponsor contribution.** Zetaris scoped CSV/NDP evidence
   queries; Meterless reference graph reads/history; Nightshift/Nemotron actual
   serving identity. Python deterministic authority stays independent. Explain
   why SQL selection and graph reads affect the investigation.
6. **Recovery with proof.** Exact dedicated synthetic target, source hashes,
   explicit review, serialized bounded write, uncertain-ack readback, same
   comparator after recovery. Show one real Central receipt, not a mockup.
7. **What was tested and what remains.** Actual Stage 7 test/performance results,
   fixture controls and limitations. Distinguish offline, saved capture and live
   calls. No global safe-to-wipe claim or production deployment claim.
8. **Next improvements.** Broader tested export compatibility, operational
   retention/authentication, larger evidence-source measurements, accessibility
   testing with real users. These are future work, not delivered capabilities.
